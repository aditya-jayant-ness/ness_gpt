# Figma Mapping Notes

This build starts a deliberate chat-centric UI baseline and will iterate toward closer parity with the provided Figma reference.

## Implemented UI Regions

1. Left utility pane
- Branding and capability summary

2. Main chat panel
- Target URL input
- Message timeline for user and assistant
- Source snippets under assistant responses
- Question composer and send action

3. Analytics panel
- Session metrics cards
- Download PDF action
